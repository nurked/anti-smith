    What these detectors cannot see

    Page-side detection is spoofable and blind to a lot. In particular: monkey-patching only sees scripts in the page's main world, not extension content scripts in their isolated world; CDP-driven input (Playwright, Puppeteer, chrome.debugger extensions) produces isTrusted: true events; pages cannot list installed extensions. Use ?skip=detector.debugger-timing to stop debugger pauses, ?only=<id>,<id> to run a subset.
